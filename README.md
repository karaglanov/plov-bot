# Бот «Маркетинговый плов»

Telegram-бот, который сам готовит посты для канала и публикует их после одобрения. Работает на Vercel круглосуточно, личный аккаунт Telegram ему не нужен.

## Что он делает

1. Читает темы группы админов «Идеи контента» и «Сырой контент» и запоминает всё, что туда пишут (ставит 👀 на сообщение, когда идея сохранена).
2. Вечером накануне дня поста (по умолчанию пн, ср, пт) берёт неиспользованную идею. Если идей нет, сам ищет тему в интернете.
3. Присылает в тему «Контент Production» готовый пост по гайду стиля, промпт для картинки и кнопки.
4. Вы генерируете картинку по промпту и отправляете её ответом на черновик. Бот показывает, как пост будет выглядеть в канале.
5. Чтобы поправить текст, отвечаете на черновик словами («сделай короче», «замени пример на кафе»).
6. После ✅ пост выходит в канал утром в день публикации. «🚀 Опубликовать сейчас» публикует сразу.
7. По воскресеньям присылает сводку: подписчики, реакции, комментарии, запас идей.

Одобрять и править посты может только владелец (тот, кто первым написал `/start`). Добавить второго человека: ответьте на его сообщение командой `/approver`.

## Установка

Нужны три вещи: токен бота, ключ Claude API и аккаунт Vercel.

1. **Бот.** В Telegram откройте @BotFather → `/newbot` → придумайте имя и юзернейм. Скопируйте токен.
2. **Ключ Claude.** На https://platform.claude.com → API keys → Create key. Пополните баланс (хватит $5–10).
3. **Vercel.** Импортируйте этот репозиторий в Vercel (Add New → Project). В поле Environment Variables вставьте сразу обе строки:
   ```
   TELEGRAM_BOT_TOKEN=токен_от_BotFather
   ANTHROPIC_API_KEY=ключ_Claude
   ```
   Нажмите Deploy.
4. **База.** В проекте Vercel: Storage → Create Database → Upstash for Redis → Create. Потом Deployments → ⋯ → Redeploy.
5. **Проверка.** Откройте адрес проекта (вида `https://ваш-проект.vercel.app`). Страница сама подключит бота и покажет, что осталось.
6. **Telegram.** Добавьте бота админом в канал (право «Публикация сообщений») и админом в группу админов. В теме «Контент Production» напишите `/start`. По желанию добавьте бота в группу с комментариями канала.
7. Напишите `/post`, чтобы получить первый черновик.

## Команды (в группе админов)

| Команда | Что делает |
|---|---|
| `/post` | Написать пост сейчас. `/post тема` пишет на заданную тему |
| `/ideas` | Показать идеи в запасе |
| `/digest` | Сводка по каналу |
| `/status` | Что настроено и что нет |
| `/ideas_here` | Брать идеи из этой темы (если бот не узнал её по названию) |
| `/drafts_here` | Присылать черновики в эту тему |
| `/approver` | Ответом на сообщение человека: разрешить ему одобрять посты |

## Настройки (Vercel → Settings → Environment Variables, все необязательные)

| Переменная | По умолчанию | Что значит |
|---|---|---|
| `CHANNEL` | `@marketing_plov` | Канал для публикации |
| `POST_DAYS` | `1,3,5` | Дни постов: 0 вс, 1 пн, … 6 сб |
| `POST_TIME_LABEL` | `10:00` | Время в подписях. Само время задаётся в `vercel.json` |
| `TZ_OFFSET_HOURS` | `5` | Часовой пояс канала (Ташкент) |
| `DIGEST_DAY` | `0` | День сводки |
| `LONG_POST_MODE` | `preview` | Длинный пост с картинкой: `preview` одним сообщением, `split` картинка и текст отдельно |
| `OWNER_ID` | нет | Telegram ID владельца, если хотите задать его заранее |
| `CRON_SECRET` | нет | Защита расписания, Vercel подставляет сам |

Время срабатывания задано в `vercel.json` в UTC: черновик в 13:00 UTC (18:00 Ташкент), публикация в 05:00 UTC (10:00 Ташкент). На бесплатном тарифе Vercel запускает задачу в течение часа после указанного времени.

## Как обновить знания бота о канале

Гайд стиля, бриф, решения и визуальный стиль лежат в `context/`. После правки запустите `npm run context` и отправьте изменения в репозиторий. Свежие решения из рабочего чата бот видит сам.

## Ограничения

- Telegram не показывает ботам просмотры постов. В сводке есть подписчики, реакции и комментарии.
- Бот видит только сообщения, написанные после его добавления в группу.
- Подпись к фото в Telegram ограничена 1024 знаками. Более длинный пост бот публикует одним сообщением, а картинку ставит большим превью над текстом.
- Посты пишет Claude через платный API. Ориентир для 3 постов в неделю: $5–10 в месяц.

## Проверка кода

`npm install && npm test` прогоняет весь сценарий без Telegram и без Claude.
